The Problem: Heavy, Opaque Security Scanners

Most commercial web security audit tools are built behind enterprise firewalls, require software installations, or persist targets into marketing databases. Developers and webmasters want to test their site's security posture quickly without setup overhead — especially for testing staging environments or personal web projects.

WafyShield was designed to fill this gap: a lightweight, serverless reconnaissance scanner that checks critical external web signals in real-time, completely client-isolated, and provides clear remediation instructions with zero data persistence.

SSRF Prevention and Request Isolation

Allowing a user to submit arbitrary URLs to a serverless node introduces severe risk of Server-Side Request Forgery (SSRF). Attackers frequently attempt to sweep local subnets or scrape internal cloud metadata environments (e.g., AWS IMDS endpoints).

IP Range Filtering
Validates target addresses and rejects private RFC 1918 and link-local ranges before outbound requests.
Edge Rate Limiting
Protects serverless endpoints from abuse through token buckets calculated in real-time per client IP subnet.
Strict Abort Timeouts
Guards with an engineered 5-second hard ceiling per fetch to prevent slow-loris connection hangs on audit endpoints.

Multi-Vector Inspection Engine

When an audit is triggered, WafyShield parallelizes multiple lightweight inspection threads without heavy browser automation.

TLS Certificate Analysis
Initiates an isolated SNI-handshake via tls.connect() on port 443 to inspect the peer certificate chain, validity window, issuer authority, and cipher suite strength.
OWASP Security Headers
Assesses compliance based on HTTP response headers: HSTS (max-age, includeSubDomains), Content-Security-Policy (script-src, frame-ancestors), X-Frame-Options, and Referrer-Policy.
Cookie Hygiene Auditing
Inspects all Set-Cookie directives for mandatory security flags including Secure, HttpOnly, and SameSite to eliminate session hijacking and CSRF vectors.

Weighted Scoring & Zero-Persistence Storage

Each security check contributes to an aggregate security score (0–100). Penalties are proportional to vulnerability severity.

To preserve user privacy, no target domains or audit summaries are written to disk or a database. State is maintained solely in the user's browser via localStorage, giving the client total control over audit history.

Technical Challenges & Insights

Handling multi-hop HTTP redirect chains proved intricate: tracking status codes across 301, 302, and 307 hops was essential to confirm whether HSTS and HTTPS enforcement actually protected the target domain or leaked information over cleartext transitions.

The resulting architecture provides a lightweight security audit utility with no application-level persistence of submitted targets or audit results.
