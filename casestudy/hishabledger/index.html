Turning an everyday tracking problem into a focused product.

Hishab Ledger is a lightweight Android ledger built for people who want a clear record of money they owe or are owed without adopting a full accounting system.

The product keeps the core interaction simple: add a shop, set an opening balance when needed, record dues and payments, then check the current balance at any time.

The hard part was not accounting. It was keeping the record understandable.

Everyday dues are often maintained through memory, notebooks, chat messages, or scattered notes. These methods can work for a while, but they make it harder to answer a basic question quickly: which shop has how much is due right now?

I approached Hishab Ledger as a small, focused product for people who want to track their own dues across different shops, rather than as a complete business accounting suite. That decision kept the experience centered on the user's immediate task instead of adding unnecessary complexity.

Clarity first. Speed second. Complexity last.

Clear Balances
The current due stays visible so users do not need to reconstruct the balance from individual transactions.
Fast Recording
Due and payment actions are kept close to each shop record to reduce unnecessary navigation.
Private by Design
The app is offline-first, keeping everyday ledger data on the device unless the user chooses to export or back it up.

A compact interface built around the balance.

The visual direction uses a restrained Material 3 system with a green accent, generous spacing, clear hierarchy, and lightweight surfaces. The goal was to make the app feel calm and practical rather than like a traditional accounting dashboard.

Small set of features, complete everyday workflow.

Multiple shops
Keep a separate balance and transaction history for each shop.
Due & payment tracking
Record additions and payments with exact timestamps and optional notes.
Opening balance
Start a record from an existing amount without manually recreating old transactions.
History & summaries
Review transaction history and see daily changes at a glance.
Backup & restore
Export a full JSON backup and restore it later with replace or merge options.
Data export
Generate CSV data and shop-wise PDF statements when a shareable record is needed.

Local-first architecture without unnecessary infrastructure.

Hishab Ledger uses Kotlin, Jetpack Compose, and Material 3. Instead of introducing a database for this product's scope, application data is stored in a private JSON file inside app storage.

This keeps the application independent of a backend and avoids requiring an internet connection for normal use. Backup and restore are explicit user actions rather than an invisible synchronization layer.

What this project taught me.

Hishab Ledger expanded my work beyond web development into Android product development, where interaction details and state management become especially important on a small screen.

The project also reinforced a useful product lesson: a smaller feature set can create a stronger experience when every feature supports the primary task. Designing the app around a clear balance, predictable transactions, and user-controlled data kept the product focused from interface to architecture.
