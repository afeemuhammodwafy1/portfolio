01 / CONCEPT & MOTIVATION

The Problem: Scientific Linguistic Barriers

NASA's Astronomy Picture of the Day (APOD) archive contains scientific explanations for decades of planetary imagery, but remains largely inaccessible to non-English speakers and lacks responsive viewing interfaces.

AstroWafy bridges this divide by providing an intuitive cosmic viewport with seamless English-to-Bengali translation, responsive date navigation, and direct high-resolution image downloads.

02 / MEDIA PIPELINES

CORS-Bypassing Blob Downloads

Directly downloading cross-origin NASA images triggers browser CORS blocks when using conventional download attributes:

Binary ArrayBuffer Streaming

Fetches media data as raw binary streams and transforms them into native client-side Blobs.

Object URL Mapping

Creates temporary URL.createObjectURL() references to initiate downloads without third-party proxies.

Automatic Cleanup

Invokes URL.revokeObjectURL() immediately following downloads to prevent memory leaks.

03 / LOCALIZATION

Dual-Engine Translation Caching

To deliver near-instant switching between English and Bengali without redundant network requests, AstroWafy caches translated records locally:

  • Compound Cache Keys: Uses format YYYY-MM-DD_locale to isolate translated responses.
  • Deterministic Terminology: Maintains consistent translations for specialized astronomical terminology across historical queries.
  • Markdown Sanitization: Ensures text formatting and scientific citations render consistently in both locales.
04 / ASYNCHRONOUS HANDLING

Race-Condition Defense

Rapidly changing dates in the calendar could trigger multiple simultaneous fetch operations, leading to out-of-order responses:

On New Date Selected: 1. Abort previous request via controller.abort() 2. Instantiate new AbortController instance 3. Dispatch fetch(url, { signal: controller.signal }) Result: Only the active date selection updates the DOM

This pattern prevents stale network responses from overwriting the viewport when users scrub quickly through archives.

05 / RETROSPECTIVE

Integration Insights & Wrap-Up

Designing around public API rate limits highlighted the importance of localized caching. Combining client-side caching with AbortController signals produced a responsive astronomy explorer that is both resilient to network variability and accessible across languages.
