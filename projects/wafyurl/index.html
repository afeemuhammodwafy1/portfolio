01 / CONCEPT & MOTIVATION

The Problem: Paywalled Link Telemetry

Commercial link shorteners regularly lock essential features—custom aliases, deep analytics, and password protection—behind recurring subscriptions while aggressively tracking end-users across domains.

WafyURL provides a transparent, zero-cost, privacy-first link infrastructure. It handles high-throughput HTTP 302 redirects with instant QR code rendering, customizable link slugs, and isolated per-link clickstream analytics.

02 / CORE ARCHITECTURE

High-Throughput Redirect Pipeline

The routing pipeline separates read paths from asynchronous metric recording. When a shortened URL slug is requested, the system resolves destination pointers instantly:

Trailing-Plus Direct Access

Appending + directly to any short slug interrupts redirection and renders real-time telemetry charts instantly.

Collision-Free Base62 Hashes

Generates compact base62 tokens derived from incremental records, ensuring collision resistance under high loads.

Instant Dynamic QR

Generates lightweight vector SVG QR matrices on-the-fly without relying on third-party tracking APIs.

03 / TELEMETRY PIPELINE

Privacy-Preserving Clickstream Analytics

Redirect events trigger non-blocking metadata logging to collect essential telemetry without storing personally identifiable information (PII):

  • User-Agent Classification: Parses client browser, OS distribution, and device viewport categories via lightweight regex rules.
  • Referral Trace Isolation: Records traffic origins (Direct, Search Engines, Social Networks) while scrubbing sensitive query strings.
  • Coarse Geo-IP Resolution: Resolves countries via localized binary IP tables without recording raw IP addresses.
04 / ACCESS CONTROL

Cryptographic Link Shielding

For sensitive or restricted internal links, WafyURL provides gated redirection channels that enforce authentication prior to forwarding:

Input Password --> Salted SHA-256 Digest --> Constant-Time Compare Auth Passed? --> HTTP 302 Redirect --> Target Destination Auth Failed? --> HTTP 401 Unauthorized --> Incremental Rate Limiting

Brute-force protection uses IP-based rate limiting on password submission endpoints, safeguarding gated links against automated dictionary attacks.

05 / RETROSPECTIVE

Database Optimization & Lessons

Handling spikes in link redirections while simultaneously logging analytics writes posed a classic database bottleneck. Adopting B-Tree composite indexes on (slug, is_active) reduced read queries to single-digit milliseconds, while connection pooling maintained stability under load.
